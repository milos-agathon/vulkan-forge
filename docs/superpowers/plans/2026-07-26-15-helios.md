# HELIOS Implementation Plan

> **For agentic workers:** Execute this plan inline, task-by-task. Every task uses test-first development and ends with focused validation, a two-axis Codex autoreview (repository standards and `docs/prompts/fable5-moonshots/15-helios.md`), corrections, a clean retest, then one scoped commit and push.

**Goal:** Add SPA-accurate solar geometry and deterministic curved/refracting-earth terrain shadow, viewshed, shadow-tip, and diagnostic APIs without a second min-max pyramid.

**Architecture:** Rust owns astronomy, refraction, geodesy, and terrain line-of-sight logic. The existing PROMETHEUS min-max texture remains unchanged; a small curvature uniform bends the ray-height comparison in the existing WGSL traversal. Python modules are typed, validation-only wrappers over registered PyO3 functions. GPU visual evidence is gated, while numeric DoD checks run deterministically without a GPU.

**Tech Stack:** Rust `f64` astronomy/geodesy, Rust/WGSL terrain traversal, PyO3/numpy, thin typed Python wrappers, pytest, cargo tests.

## Global Constraints

- No new dependencies or feature flags.
- Default physics is WGS84 ellipsoid plus Bennett refraction; flat/none remains an explicit ablation.
- Unsupported earth/refraction values fail at the boundary.
- Orthometric DEM inputs require an explicit `orthometric_egm96` height-system declaration.
- No second min-max texture; all GPU allocations use the existing CENSOR tracker.
- After every Rust/WGSL change: `cargo fmt --check`, `maturin develop --release`, and `cargo forge3d-clippy`.
- Register native functions, package exports, stubs, and `tests/test_api_contracts.py` together.
